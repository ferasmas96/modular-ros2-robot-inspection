# Task figures and documentation

When a task produces or supplies maps, plots or diagrams, save reusable exports in
`evidence/figures/<TASK-ID>/`. Do not generate a figure merely to fill a folder.

- Follow `evidence/figures/README.md` and its task README template.
- Keep the image/export and any available editable or plotting source together.
- Use dated, descriptive, versioned filenames; preserve existing versions and original downloads.
- Record captions, source task/run, frames/units, rendering method when known and relevant limitations.
- Add actual files to the central figure index and link them from relevant project documentation.
- If figures were created in another ChatGPT conversation, locate the user's downloaded files or ask for their location. Do not claim they are archived until the files are copied and checked.
- Retain existing legacy figure paths and links. Index them rather than moving/deleting them during routine work.
- Keep bulk native maps, bags, private settings and raw logs in their private run directories, outside this figure archive.

Archiving figures does not authorize a runtime experiment, installation, commit or push.
